## 作ったもの・書いたもの

### tanacode（OSS）

[tanacode](https://github.com/sny-tanaka/tanacode) は、「Claude Code の中身が見える。できることが増える。」をうたう、個人で作っている非公式の macOS アプリです。Claude が読んだファイルやコンテキストの中身、サブエージェントの動きをチャットの横に表示し、ブラウザでの確認・チェックリスト・子セッション・ウォークスルー・ターミナルの 5 つの MCP を Claude Code に足します。中では `claude` CLI をそのまま動かしています。

- [ブラウザでデモを試す](https://sny-tanaka.github.io/tanacode/)（インストール不要）
- Electron・React・TypeScript で開発。画面は日本語と英語に対応
